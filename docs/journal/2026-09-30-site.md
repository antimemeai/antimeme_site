# The first shingle

Build a quiet, single-page site for antimeme.ai: near-white cream, black typography,
small typewriter details, and generous space. The operator will write the final copy;
the initial text establishes the hierarchy and is deliberately brief. Contact:
hiya@antimeme.ai.

Implementation: semantic HTML and one stylesheet in `public/`, with locally served
Inter Tight and IBM Plex Mono. No JavaScript, libraries, frameworks, external font
requests, or build process. Use fine rules rather than boxes to organize the three
services. Scale the typography and stack the layout on narrow screens. Provide a
small local preview script and document Cloudflare Pages configuration.

Check the result in a real browser at desktop and phone widths, including overflow,
font loading, keyboard focus, and the email link. Review the final source before
committing.

Completed the first layout and inspected desktop (1440px) and phone (390px)
screenshots in Chrome. Browser checks at 320, 390, 768, 1024, and 1440px found
no horizontal overflow; both local fonts loaded; the email target was correct;
the page had no scripts or external resource requests. Keyboard traversal showed
the wordmark's visible focus outline. An independent source review found no
actionable accessibility or static deployment issues.

Cloudflare's static HTML documentation supports deploying `public/` directly with
the `None` preset and `exit 0` as the build command. The GitHub remote was empty at
the start of this session; the first push establishes `master`.
